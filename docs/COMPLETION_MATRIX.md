# Completion Matrix

A feature is COMPLETE only when every applicable gate is PASS.

- UI
- API
- Validation
- Authentication
- Authorization
- Tenant isolation
- Data scope
- Database
- Migration
- Loading state
- Empty state
- Error state
- Audit/activity
- Tests
- Runtime verification
- Spectator verification
- Security review (risk-based)
- Performance review (risk-based)
- Documentation

Builder success is not completion. Evidence is required.
