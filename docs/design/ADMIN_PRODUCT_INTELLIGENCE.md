# Admin Product Intelligence System

Admin UI is a product surface, not a collection of pages. Before implementation establish the user/persona, primary job, task frequency, decisions, information needs, entities/relationships, constraints, operational states, exceptions, action hierarchy, workspace pattern, search/filter/saved-view needs, audit/activity needs, responsive strategy, and acceptance criteria.

A visually polished interface that makes the administrator take unnecessary steps is a UX failure. Prefer the fastest safe path to the real job while preserving permissions, auditability, business rules, and context.
