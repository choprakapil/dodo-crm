# Admin Workspace Patterns

Evaluate table/list, queue, compact metrics + table, master-detail, split workspace, contextual drawer, timeline, attention queue, focused form, dedicated route, and wizard. Choose the simplest pattern that supports the job.

Use tables for comparison, queues for review/triage, master-detail for scan+inspect, drawers for contextual detail, modals for focused decisions/forms, routes for substantial workflows, timelines for history, and attention queues for exceptions.

Do not default to giant title + four cards + tabs + table + generic modal.
