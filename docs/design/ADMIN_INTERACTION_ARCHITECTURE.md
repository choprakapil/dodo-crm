# Admin Interaction Architecture

Inline = quick/low-risk/reversible/common. Drawer = contextual inspection while retaining workspace context. Modal = focused decision or short form. Route = substantial/deep-linkable workflow. Wizard = genuinely multi-step process. Bulk = repetitive selected-record operations.

Keep context, make the next safe action obvious, derive actions from state+permission, preserve useful filters/selection, and provide recovery for failed operations.
