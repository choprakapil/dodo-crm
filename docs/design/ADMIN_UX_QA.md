# Admin UX QA

A workspace passes when the primary task can be completed, the next action is understandable, important information is visible at the right level, related entities are reachable, actions respect state and permission, relevant states exist, failures are recoverable, modals/drawers are justified, responsive behavior preserves the workflow, and browser/screenshot evidence is supplied when tooling allows.

A pretty screenshot is not sufficient UX evidence.
