# Session Close Protocol

Every item below must reflect what actually happened this session, not a
summary of intentions. See `docs/EVIDENCE_STANDARDS.md`.

Before ending:
1. Record task state.
2. List exact files changed.
3. Record commands/tests and outcomes.
4. Record browser/E2E evidence.
5. Record known issues.
6. Update next task.
7. Update architecture/API/database/security/test state.
8. Update changelog and handoff.
