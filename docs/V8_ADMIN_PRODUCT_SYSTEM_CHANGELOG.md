# V7 → V8 Admin Product System Changelog

## Why V8 exists

V7 established strong governance, evidence, design tokens, design QA, mobile coordination, and reusable engineering procedures. V8 adds a product-experience layer for admin/internal interfaces so the AI does not stop at technically correct but generic screens.

## Behavioral change

For significant admin/internal UI work, the AI must reason about the administrator's job, workspace, state machine, relationships, action placement, productivity, attention, auditability, and evidence before treating the screen as complete.

## Compatibility

V8 retains the existing V7 file structure and previous agents/skills. The expansion is additive and does not remove the prior governance, engineering, security, mobile, design-system, or evidence controls.
