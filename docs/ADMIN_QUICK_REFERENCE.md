# Admin Quick Reference

“Create a page” → identify the administrator job.

“Manage records” → evaluate table/list, queue, master-detail, and drawer.

“Edit” → decide inline vs drawer vs modal vs route; do not default to modal.

“Has statuses” → run Workflow & State Architecture.

“Has relationships” → run Entity Relationship Architecture.

“Many actions” → run Action Architecture.

“Feels boring” → improve workflow, attention, drill-down, activity, and contextual interaction before adding decoration.

“Looks generic” → run Anti-Generic Admin UI.

“Looks wrong” → run Screenshot QA + Design QA.

“Works but feels slow” → run Admin UX Regression.
