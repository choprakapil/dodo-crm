# Admin Product Build Protocol

1. Product Intelligence
2. Admin Experience
3. Workspace Architecture
4. Workflow/State Architecture when applicable
5. Entity Relationship Architecture when applicable
6. Action Architecture
7. Design System
8. Implementation
9. Screenshot QA
10. UX Regression
11. Accessibility/Security/Route/Functional QA
12. Evidence + Memory Update

Before implementation, produce Product Intelligence Brief, Workspace Brief, State Matrix where applicable, Entity Relationship Map where applicable, and Action Placement Matrix.

After implementation, record browser/screenshot evidence when available, UX regression walkthrough, tests, limitations, and memory updates.
