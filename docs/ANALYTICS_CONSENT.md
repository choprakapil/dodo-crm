# Analytics, Privacy & Consent

## Data Collection

List every analytics/marketing/monitoring tool and:
- purpose;
- events;
- data collected;
- retention;
- third parties;
- failure behavior.

## Consent

If consent is legally/organizationally required:
- non-essential tracking must not fire before consent;
- preference changes must take effect;
- consent state must persist appropriately;
- analytics failure must never block core UX.

## Event Design

Use a small documented event vocabulary. Do not add tracking ad hoc inside components without a defined contract.
