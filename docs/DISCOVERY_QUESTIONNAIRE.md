# Discovery Questionnaire

## Identity
1. Project name?
2. One-sentence purpose?
3. What problem does it solve?
4. Who are the users?
5. What is explicitly out of scope?

## Product
6. Core workflows?
7. Required features?
8. User roles and permissions?
9. Business rules?
10. Success criteria?

## Platforms
11. Web, iOS, Android, desktop, API, admin?
12. Responsive requirements?
13. Browser/device support?

## Data
14. Entities?
15. Relationships?
16. Required fields and validation?
17. Retention/deletion rules?

## Backend/API
18. Required services?
19. Authentication?
20. RBAC?
21. API style?
22. Webhooks?
23. Background jobs?

## Integrations
24. Payments?
25. Email/SMS/WhatsApp?
26. Maps/location?
27. Analytics?
28. Storage/CDN?

## UI/UX
29. Brand/design system?
30. Existing references?
31. Accessibility?
32. Empty/loading/error states?

## Admin
33. Admin roles?
34. Moderation/operations?
35. Reporting?
36. Audit logs?

## Security
37. Sensitive data?
38. Threats/abuse cases?
39. Rate limits?
40. Secrets/configuration?

## Delivery
41. Hosting?
42. Environments?
43. CI/CD?
44. Monitoring?
45. Backup/recovery?

## Quality
46. Required test levels?
47. Browser/E2E requirements?
48. Cross-platform requirements?
49. Performance targets?
50. Release criteria?

Continue asking questions until no material ambiguity remains. Save answers before implementation.
