# Completion Gates

Each checkbox requires attached evidence per `docs/EVIDENCE_STANDARDS.md`.
Ticking a box without evidence is a false completion claim, not a shortcut.

- [ ] Requirements traceability — evidence: updated row(s) in `REQUIREMENTS_TRACEABILITY.md`
- [ ] Feature completion matrix — evidence: updated row(s) in `FEATURE_COMPLETION_MATRIX.md`
- [ ] Route/link audit — evidence: checked routes/links and observed destinations
- [ ] API contract audit — evidence: real request/response exchanged with a real consumer
- [ ] Code reuse/dead-code audit — evidence: search performed and its result
- [ ] Security gate — evidence: specific unauthorized/invalid case tested and result
- [ ] Tests — evidence: actual command + output (pass/fail counts)
- [ ] Browser/E2E verification — evidence: concrete steps taken and observed result
- [ ] Documentation — evidence: which doc(s) updated
- [ ] State persistence — evidence: which `docs/memory/*.md` file(s) updated
- [ ] Completion auditor sign-off — evidence: adversarial review notes, not a rubber stamp
