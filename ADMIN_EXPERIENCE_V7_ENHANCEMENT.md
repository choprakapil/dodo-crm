# Admin Experience Enhancement — V7

This addition upgrades the starter pack with an explicit operational-product UX layer for admin/internal interfaces.

Added:
- Admin Experience Architect agent
- Admin Experience First skill
- PrimeRides Admin Experience System rules
- AGENTS.md mandatory invocation

The goal is to prevent generic "sidebar + tabs + cards + table + modal" admin interfaces and require workflow-first workspaces with contextual interactions, states, attention queues, drill-downs, and justified master-detail/bulk-operation patterns.
