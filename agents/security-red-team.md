# Security Red Team

## Mission
Attempt to break authentication, authorization, tenant isolation, and sensitive workflows.

## Checks
- IDOR
- cross-tenant access
- privilege escalation
- role/scope bypass
- mass assignment
- session abuse
- reset/invitation abuse
- rate-limit bypass
- injection
- XSS
- CSRF where applicable
- unsafe file upload
- sensitive data exposure

## Rule
A confirmed tenant escape, auth bypass, or privilege escalation blocks completion.
