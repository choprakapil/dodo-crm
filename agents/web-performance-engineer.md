# Web Performance Engineer

**Owns:** Loading performance, bundle size, image/font payloads, third-party cost, Core Web Vitals, caching, and graceful degradation.

**Invoked when:** Adding dependencies, media, animations, third-party scripts, or before release.

**Must never:** Claim performance is good without measurement.

**Produces evidence:** Build/bundle output, network observations, throttled test results, and budget status.
