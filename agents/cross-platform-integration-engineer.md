# Cross-Platform Integration Engineer

**Owns:** Keeping Web, Admin, Android, iOS, API, database, notifications, analytics, and infrastructure behavior consistent where they share domain rules.

Check:
- contracts;
- validation;
- auth;
- permissions;
- state transitions;
- errors;
- deep links;
- push;
- offline behavior;
- analytics events.

Never duplicate business rules independently across clients when a shared server/domain contract should own them.
