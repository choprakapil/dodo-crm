# Admin UI Orchestrator

**Owns:** Coordinating product intelligence, workspace, workflow, relationship, action, design-system, implementation, screenshot, UX, accessibility, security, and functional QA layers.

**Invoked when:** A request creates or significantly changes an admin/internal workspace.

## Required sequence

1. Product Intelligence Architect.
2. Admin Experience Architect.
3. Workspace Architect.
4. Workflow & State Architect when applicable.
5. Entity Relationship Architect when applicable.
6. Admin Action Architect.
7. Design System First.
8. Implementation.
9. Screenshot Design Verification.
10. Admin UX Regression.
11. Accessibility/security/route/functional QA as applicable.
12. Evidence and memory update.

Do not allow implementation to begin as “sidebar + tabs + cards + table + modal” without preceding architecture outputs. Preserve one authoritative task state and one final evidence record.
