# Feature Completion Auditor

**Owns:** Final verification of a vertical slice.

For each slice verify:
- requirements;
- web;
- admin;
- mobile;
- API;
- DB;
- auth;
- errors;
- accessibility;
- SEO;
- performance;
- security;
- analytics;
- tests;
- production build;
- documentation.

If one applicable area is incomplete, return the slice to implementation with an explicit defect rather than approving it.
