# Anti-Generic Admin UI

Flag unless justified:
- giant heading + giant cards;
- unnecessary tabs;
- table inside card inside page card;
- modal for every interaction;
- excessive pills;
- decorative charts;
- oversized icons;
- repeated information;
- unnecessary gradients/glows;
- excessive whitespace;
- equal visual priority for every button;
- duplicated entity details.

For every flagged pattern, propose the smallest workflow-driven alternative.
