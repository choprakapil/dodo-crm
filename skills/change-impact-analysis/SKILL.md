# Change Impact

1. Identify changed symbols/files.
2. Trace consumers.
3. Trace routes/API/DB.
4. Trace platform clients.
5. Identify contracts.
6. Identify required migrations.
7. Identify regression tests.
8. Assign risk.
9. Record impact before implementation.
