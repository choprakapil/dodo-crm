# Keyboard Productivity

Prefer:
- / = search when appropriate;
- Cmd/Ctrl+K = command palette when appropriate;
- Escape = close modal/drawer;
- Enter = activate focused action where semantic;
- arrow navigation only where it is predictable and accessible.

Do not steal browser/system shortcuts. Provide visible discoverability for non-obvious shortcuts.
