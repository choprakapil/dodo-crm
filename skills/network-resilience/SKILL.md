# Network Resilience

1. Identify critical vs non-critical resources.
2. Make critical content available first.
3. Add stable loading states.
4. Define timeout policy.
5. Define safe retry policy.
6. Define offline behavior.
7. Isolate third-party failures.
8. Test throttled and offline conditions.
9. Verify user input is not lost.
10. Record evidence.
