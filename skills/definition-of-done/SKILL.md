# Definition of Done

**Purpose:** Code existing is not the same as a task being done. Tests, verification, audit, documentation, and persistent state must all be complete.

## When to use this skill
Use as the final check before marking any task or feature complete.

## Steps
1. Walk `docs/COMPLETION_GATES.md` for this task's scope.
2. For every gate, confirm evidence exists per `docs/EVIDENCE_STANDARDS.md` — not just a checkbox.
3. If any gate lacks evidence, the task is BLOCKED or IN PROGRESS, never COMPLETE.

## Evidence required
A completed `docs/TASK_TEMPLATE.md` entry with evidence attached to every applicable gate.

Do not mark work that uses this skill as complete without the evidence above. See `docs/EVIDENCE_STANDARDS.md` for the general evidence rules.
