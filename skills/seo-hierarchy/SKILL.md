# SEO Hierarchy

1. Map route intent.
2. Define one intentional H1.
3. Define H2/H3 hierarchy.
4. Define title/description/canonical/indexability.
5. Audit internal links.
6. Generate and inspect sitemap/robots.
7. Validate structured data only where truthful.
8. Audit image alt text.
9. Crawl actual rendered routes.
10. Record route-level evidence.
