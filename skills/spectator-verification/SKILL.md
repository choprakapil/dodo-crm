# Spectator Verification

1. Read acceptance criteria.
2. Inspect actual diff.
3. Inspect dependency impact.
4. Run targeted tests.
5. Run critical runtime flow.
6. Check failure paths.
7. Check console/logs.
8. Check affected platforms.
9. Search for stubs/TODOs/mock production behavior.
10. Produce PASS/FAIL/BLOCKED with evidence.
