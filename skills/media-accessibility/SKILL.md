# Media Accessibility & Optimization

1. Classify every media asset.
2. Define alt behavior.
3. Define dimensions/aspect ratio.
4. Choose loading priority.
5. Choose responsive sources/formats.
6. Verify no avoidable layout shift.
7. Test failed media behavior.
8. Test keyboard/screen-reader meaning where relevant.
9. Verify mobile art direction.
10. Record evidence.
