# Project Map

**Purpose:** Maintain a current map of routes, components, APIs, data entities, integrations, jobs, and dependencies so the AI never has to guess the project's shape.

## When to use this skill
Use when the project structure changes (new route, API, integration, or major component) or before starting unfamiliar work.

## Steps
1. Before starting work in an unfamiliar area, read `docs/memory/PROJECT_MAP.md` and `docs/memory/ROUTES.md` first.
2. After any structural change, update the map in the same task, not in a later cleanup pass.

## Evidence required
The updated map file plus a one-line note of what changed and why.

Do not mark work that uses this skill as complete without the evidence above. See `docs/EVIDENCE_STANDARDS.md` for the general evidence rules.
