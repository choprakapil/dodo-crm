# Screenshot QA Loop

IMPLEMENT → RUN → CAPTURE → INSPECT → COMPARE → FIX → CAPTURE AGAIN.

Inspect typography, spacing, alignment, density, hierarchy, overflow, responsive states, token consistency, table readability, and accidental generic/oversized UI. If browser capture is unavailable, record BROWSER VISUAL VERIFICATION BLOCKED and do not claim visual completion.
