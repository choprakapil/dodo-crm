# Workspace Architecture

Evaluate table/list, queue, compact metrics + table, master-detail, split workspace, timeline, attention queue, focused form, and wizard patterns.

For the chosen pattern define:
- scan surface;
- attention surface;
- primary data surface;
- filters/search;
- selection behavior;
- detail behavior;
- actions;
- history/activity;
- responsive transformation.

Reject patterns that increase unnecessary navigation or scrolling.
