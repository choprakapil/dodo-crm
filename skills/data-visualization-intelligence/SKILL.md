# Data Visualization Intelligence

Use TABLE for record comparison.
Use KPI for a small number of important values.
Use CHART for trends/patterns where a visual trend adds information.
Use TIMELINE for history.
Use PROGRESS for completion.
Use DISTRIBUTION when composition matters.

Do not add charts merely because a dashboard has empty space. Each visualization must support a real decision.
