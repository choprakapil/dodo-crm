# Repository Cartography

1. Identify repo root and instructions.
2. Inventory meaningful files.
3. Identify stack and package managers.
4. Map routes.
5. Map APIs.
6. Map DB entities/migrations.
7. Map symbols/imports/exports.
8. Map tests.
9. Build dependency graph.
10. Record generated/stale/dead areas.
11. Save compact indexes with commit/hash.
12. Return only the relevant subset for the active task.
