# Admin Action Hierarchy

For every action define actor, permission, precondition, placement, priority, confirmation, loading, success, failure, and recovery.

Placement rules:
- inline = quick/low-risk/reversible;
- drawer = contextual inspection + action;
- modal = focused decision/form;
- route = substantial/deep-linkable workflow;
- wizard = genuinely multi-step;
- bulk = repetitive operations.
