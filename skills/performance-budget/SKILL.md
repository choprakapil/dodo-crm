# Performance Budget

1. Read `docs/PERFORMANCE_LIGHTWEIGHT_SCALABILITY.md`.
2. Freeze measurable budgets.
3. Audit dependencies and third-party scripts.
4. Inspect bundle/chunk behavior.
5. Audit image and font payloads.
6. Test cold and repeat loads.
7. Test throttled mobile network.
8. Review layout shifts and long tasks.
9. Fix budget violations.
10. Rerun and record evidence.
