# Requirements Question Loop

**Purpose:** Ask focused follow-up questions until no material ambiguity remains, instead of guessing what the user meant.

## When to use this skill
Use during discovery whenever a requirement is ambiguous, incomplete, or contradictory.

## Steps
1. When an answer is vague, ask a specific, narrow follow-up rather than a broad re-ask.
2. Persist every answer immediately in the relevant spec/discovery file.
3. Never invent a business rule, permission, or workflow detail that was not actually stated or confirmed.

## Evidence required
The specific question asked and the answer recorded, with a file/line reference to where it was saved.

Do not mark work that uses this skill as complete without the evidence above. See `docs/EVIDENCE_STANDARDS.md` for the general evidence rules.
