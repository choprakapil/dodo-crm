# Admin UX Regression

Run a realistic administrator task walkthrough. Record task, observed steps, expected result, actual result, unnecessary steps, failures, severity, and evidence. Check primary task completion, navigation, modal/drawer count, information visibility, state transitions, error recovery, filter/search behavior, keyboard use, and responsive behavior.
