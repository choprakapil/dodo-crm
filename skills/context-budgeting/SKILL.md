# Context Budgeting

1. Start with indexes.
2. Retrieve only relevant files.
3. Prefer symbols/ranges.
4. Avoid repeated reads.
5. Persist stable decisions.
6. Summarize large logs.
7. Use risk-based test selection.
8. Keep handoffs compact.
9. Drop transient context after persistence.
10. Escalate context size only when evidence requires it.
