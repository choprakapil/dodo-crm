# Task Decomposition

**Purpose:** Break the frozen plan into small, independently verifiable, end-to-end tasks. Exactly one task is active at a time.

## When to use this skill
Use when turning a frozen specification or master plan into actionable work.

## Steps
1. Create each task using `docs/TASK_TEMPLATE.md` with a clear objective and acceptance criteria.
2. Size each task so it can be fully completed (all applicable layers) and verified on its own.
3. Check `docs/TASK_REGISTRY.md` to confirm only one task is IN PROGRESS before starting a new one.

## Evidence required
A `docs/TASK_REGISTRY.md` row with a single IN PROGRESS task and clear dependencies.

Do not mark work that uses this skill as complete without the evidence above. See `docs/EVIDENCE_STANDARDS.md` for the general evidence rules.
