# Antigravity Configuration

This file is read automatically by Google Antigravity and takes precedence
over `AGENTS.md` when the two differ. Currently it simply points to the
shared `AGENTS.md` so Cursor, Claude Code, and other tools reading the same
repo see the same rules.

If you need Antigravity-specific rules that should not apply to other tools,
add them here instead of editing `AGENTS.md`.

For now: **Read `AGENTS.md` as the governing file.**

This project uses the V8 Admin Product System expansion. Read AGENTS.md for the authoritative admin product workflow.
